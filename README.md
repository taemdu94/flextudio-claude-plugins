# Flextudio Claude plugins

플렉스튜디오(Flextudio) 로우코드 개발자를 위한 Claude 플러그인 마켓플레이스입니다.
Claude plugin marketplace for developers who build apps with Flextudio, a low-code platform by YoungLimWon SoftLab.

## 설치 / Install

```
/plugin marketplace add taemdu94/flextudio-claude-plugins
/plugin install flextudio@flextudio
```

## 들어 있는 플러그인 / Plugins

| 플러그인 | 내용 |
|---|---|
| [flextudio](plugins/flextudio) | 플렉스튜디오 개발 도우미 스킬(시나리오·스크립트·K-System 연동·배포·신규 기능) |

The `flextudio` plugin adds the `flextudio-dev-helper` skill. When you ask Claude about Flextudio Studio scenarios, events and scripts, K-System ERP stored procedures and FlexAPI, FlexSQL, deployment, installation, printing, or the new FlipFront and FlipBack features, the skill answers from official documentation and verified behavior instead of guessing function names.
