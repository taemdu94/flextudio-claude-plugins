# 바뀐 내용

## 0.1.0 (2026-11-03)

- 첫 판(사내 검토용).
- 범위: 기존 로우코드 방식(Studio 시나리오, 이벤트, 스크립트, K-System SP, FlexSQL, 배포).
- 참조 파일 11개, SP 뼈대 3종, 화면 정의 양식, 문의 양식.
- 아직 넣지 않은 것: 플립프론트·플립백(신규 기능).

## 0.2.0 (2026-11-03)

- 1차 평가(48문항)와 실습 시험 결과를 반영했습니다.
- 추가: 자주 묻는 질문(faq.md), 공식 스크립트 함수 목록 2개(319개), 테이블 뼈대(table.sql).
- 고침: SP 단독 시험 예시에 관리 컬럼 전체와 임시 테이블 정리 줄, 관리 컬럼 타입, Q조회/R조회 고르는 기준, DB 권한 오류 안내, 코드도움 오류 확인 순서, 같은 시나리오 안 목록→상세 예제.
- 규칙: 답에 스킬 파일 경로를 쓰지 않고 내용을 옮겨 적습니다. 함수 이름은 공식 목록이나 참조 파일에 있는 것만 씁니다.

## 0.3.0 (2026-11-03)

- 공식 문서를 근거로 컨트롤 카탈로그(controls-catalog.md)와 콘솔·도구 안내(console-and-tools.md)를 추가했습니다.
- 화면 정의 양식의 결과 키 [Etc] 등록 안내를 확정 문장으로 맞추고, SP 단독 시험 예시의 컬럼 타입을 K-System 서비스 설명과 같게 했습니다.
- 참조 파일끼리 가리킬 때 파일 이름 대신 주제 이름을 씁니다.

## 0.4.0 (2026-11-03)

- 공식 스크립트 명세 319쪽을 이름공간별 요약 5개(references/spec/)로 넣었습니다. 함수마다 개요, 파라미터(필수 여부·타입·설명), 기본값, 예시 앞부분이 있습니다.
- 0.3.0 독립 평가에서 파라미터 뜻과 기본값을 몰라 틀린 문항(버튼 색 인자, 토스트 기본값, 비동기 설정 등)을 줄이기 위한 것입니다.

## 0.5.0 (2026-11-04)

- 참조 파일 6개를 더했습니다.
  - 문의 사례(qna-cases.md): 실제 문의에서 반복된 질문을 증상, 원인, 확인, 해결로 일반화했습니다.
  - 하기 쉬운 실수(common-mistakes.md): 검증된 함정과 SP 를 넘기기 전 추가 점검을 모았습니다.
  - 네트워크와 설치(network-and-install.md): 방화벽 요청 항목, 출발지 IP, Flex-K 연결 점검 순서, 사용자 동기화, 사내망 차단을 다룹니다.
  - 출력과 장비(devices-and-printing.md): 출력 방식 비교, 출력 연결 프로그램, OZ 출력, PDA 스캐너, 모바일 앱 빌드를 다룹니다.
  - 공식 문서 세부(official-docs-extra.md): Firestore, 스텝 버튼 이동 타입 5종, 권한키 관리를 다룹니다.
  - 신규 기능(flip-new-features.md): 플립프론트와 플립백의 사용자 관점 동작과 제약입니다. 이전 판의 "범위 밖" 안내를 바꿨습니다.
- 고침: f.MessageBox 버튼 함수 이름을 공식 명세의 addBtn 으로 확정했습니다. f.Auth.check 반환값(true, false)과 스텝 버튼 이동 타입 다섯 가지를 적었습니다.
- 고침(2026-11-06): 비동기 서비스 호출 설명을 바로잡았습니다. 스위치 위치([서비스 고급설정]의 [비동기 호출 사용하기], 데이터소스에는 없음), 동기와 비동기의 차이(대기, 로딩 화면, 실패 시 오류 창과 남은 액션 취소, Async Catch Script, 디버그 로그), 자동 조회가 한 번 실패한 뒤 멈추는 함정, f.Setting.User.set 을 한 스크립트에서 여러 번 부를 때와 1 Kbyte 한도를 더했습니다.
