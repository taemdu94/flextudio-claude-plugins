## 1. 시트

### 1-1. 시트 헤더를 두 줄로 묶어(병합 헤더) 보여 주고 싶습니다
결론: 속성 패널에는 없고, 시트 로드 스크립트의 사용자 설정(nestedHeaders 옵션)으로만 만들 수 있습니다.
할 일:
1. 시트 로드 스크립트의 사용자 설정에 nestedHeaders 를 넣어 위 줄 제목과 묶을 컬럼 수를 정하세요. 컬럼 순서 바꾸기(colMove)를 켰다면 헤더 배열도 직접 다시 계산하세요.
[확인 필요] 사용자 설정을 넣는 함수 이름은 공식 명세 목록에 없습니다. Studio [함수 자동 생성]에서 시트 로드 스크립트 항목을 확인하세요.

### 1-2. 엑셀을 올렸는데 시트에 안 보이거나 "등록된 내용이 없습니다"가 나옵니다
결론: `f.Sheet.insert` 로 올린 뒤에는 시트를 감싼 그룹을 다시 그려야 보입니다. 메시지가 나오면 엑셀 양식이 맞지 않는 경우입니다.
할 일:
1. 업로드 뒤 실행되는 이벤트 끝에서 `f.Content('<그룹fid>').reload()` 하세요.
2. 메시지가 나오면 엑셀의 행 구성을 공식 명세 f.Sheet.insert 절의 예시와 비교하세요. 답변 사례에서는 비어 있던 3번째 행을 채우자 동작했습니다.
참고: `f.Sheet.insert`·`f.Sheet.download` 는 PC 웹에서만 동작합니다.

### 1-3. 체크박스 컬럼으로 고른 행만 Selected 로 모으고 싶습니다
결론: 체크박스 컬럼의 Change 이벤트에서 그 행 섹터를 select 하거나 unSelect 하세요.
할 일:
1. 체크박스 컬럼 Change 이벤트 스크립트에 넣으세요.
```javascript
const sector = _c.<카테고리명>.activeSector;
if (sector.isSelected) { sector.unSelect(); } else { sector.select(); }
```
[확인 필요] 체크를 누를 때 그 행이 activeSector 로 잡히는지 디버거 콘솔 탭에서 먼저 보세요. 시트는 한 번 클릭으로 activeSector 가 바뀌지 않을 수 있습니다.

### 1-4. 시트 짧은 답
| 질문 | 결론 | 할 일 |
|---|---|---|
| 제목 행을 눌러 정렬하고 싶습니다 | 컬럼 하위 속성 [컬럼단위 정렬 사용]이 있습니다 | 복잡한 기준은 `f.SheetControl(fid, sector).sort(keyOrFn, order)` 를 쓰세요 |
| 두 카테고리를 엑셀 한 파일로 내려받고 싶습니다 | `f.Sheet.download` 는 카테고리 1개만 받습니다 | 스크립트로 합친 행을 새 카테고리에 만든 뒤 내려받으세요 |
| [최소 빈 행]을 쓰면 체크만 해도 행이 늘어납니다 | 빈 행을 더블클릭·체크·입력하는 순간 행이 추가되는 것이 기본 동작이고, 막는 설정과 빈 행 수를 스크립트로 바꾸는 방법은 없습니다 | 최소 빈 행을 끄고 `f.SheetControl(...).addEmptyRow(num)` 으로 필요한 만큼 넣으세요 |
| 시트 컬럼 연결에 `{% %}` 를 쓰고 싶습니다 | 시트 컬럼은 템플릿 표기를 지원하지 않습니다 | 조회 SQL 에서 표시 값을 만들어 오거나 스크립트로 `set` 하세요 |
| 다이얼로그 스텝을 열면 아래 스텝의 시트가 사라집니다 | 화면 자원 관리를 위한 의도된 동작입니다 | 다이얼로그에서 아래 시트를 직접 참조하지 않게 구성하세요 |
| 시트 콤보·서치 칸 값을 지울 수 없습니다 | 답변 당시 결함으로 확인되어 Delete 키로 지우게 수정 예정이었습니다 | [확인 필요] 지금 Delete 키로 지워지는지 확인하세요 |
| 비활성(DIS) 칸에 붙여넣기가 안 됩니다 | 복사는 되지만 붙여넣기는 지원하지 않습니다(답변 당시) | 붙여넣을 칸은 편집 가능 상태로 두세요 |

## 2. 입력·표시 컨트롤

### 2-1. 입력창 오른쪽 X 를 눌러도 값이 안 지워집니다
결론: X(입력창 삭제)는 [컬렉션-데이터소스 키 연결]에 적은 키만 지웁니다. 표시하는 컬렉션 키와 연결한 키가 다르면 지워지지 않습니다.
할 일:
1. 컨트롤의 [컬렉션 키]와 [컬렉션-데이터소스 키 연결]의 키 이름을 같게 맞추세요.
2. [입력창 삭제 버튼 사용] 토글이 안 바뀌면 컨트롤 상태를 잠시 [활성화]로 바꾸고 끈 뒤 [필수입력]으로 되돌리세요. 답변 당시 필수입력 상태에서 토글이 안 바뀌는 결함이 있었고, 지금 상태는 [확인 필요]입니다.

### 2-2. Text 컨트롤에서 연속 공백이 한 칸으로 줄어듭니다
결론: 화면에서 연속 공백이 합쳐지기 때문입니다. 줄바꿈 없는 공백 문자로 바꾸면 그대로 보입니다.
할 일:
1. 속성에 직접 쓰는 글자는 공백 자리에 `&nbsp;` 를 넣으세요.
2. 사용자가 입력한 값은 로드 스크립트에서 `Load.control.text((Load.sector.<키> || '').replace(/ /g, ' '));` 로 바꿔 보여 주세요.
3. 숫자 값을 `Load.control.text` 에 그대로 넣으면 "e.replace is not a function" 이 납니다. `String(값)` 으로 바꿔 넣으세요.

### 2-3. 날짜를 요일과 함께 보여 주고 싶습니다
결론: 기본 형식에는 요일이 없습니다. 첫 스텝에서 전역 함수를 만들고 [표시될 텍스트]에서 부르세요.
할 일:
1. 시나리오 첫 스텝 Init 이벤트 스크립트에 함수를 정의하세요.
```javascript
_v.dateWithWeekday = (d) => { const t = f.Date(d); return `${t.format('YYYY-MM-DD')} (${t.getWeekDay()})`; };
```
2. InputDate 의 [표시될 텍스트]에 `{% return _v.dateWithWeekday(Load.sector.<날짜키>) %}` 를 넣으세요.
[확인 필요] 쓸 수 있는 형식 기호와 getWeekDay 가 돌려주는 글자는 공식 명세 f.Date 절에서 확인하세요.

### 2-4. 라디오박스에서 첫 항목을 기본 선택하거나 항목 하나를 막고 싶습니다
결론: 라디오박스의 After 스크립트에서 항목마다 데이터(dsData)를 보고 상태를 정할 수 있습니다.
할 일:
1. 첫 항목 기본 선택은 After 스크립트에 넣으세요.
```javascript
const ctg = _c.<카테고리명>;
if (!ctg || !ctg.activeSector || !ctg.activeSector.<키>) { Current.radiobox.item.check = true; }
```
2. 특정 항목 비활성은 `if (dsData.<컬럼> === '<값>') { Current.radiobox.item.disabled = true; }` 로 하세요.
[확인 필요] dsData 와 Current.radiobox 는 공식 명세 목록에 없습니다. 답변 당시 `item.visible` 은 동작하지 않는 결함이 있었습니다. Studio [함수 자동 생성]과 릴리즈 노트로 확인하세요.

### 2-5. 캘린더 컨트롤 짧은 답
| 질문 | 결론 | 할 일 |
|---|---|---|
| 일정을 시작일~종료일 막대로 보여 주고 싶습니다 | 기간 단위 표시는 지원하지 않습니다(답변 당시) | 날짜마다 같은 일정을 넣어 보여 주세요 |
| 오늘 이전 날짜를 못 고르게 하고 싶습니다 | 로드 스크립트에서 기준일 이전을 막는 방법이 안내됐습니다 | [확인 필요] 안내된 `disabledBefore('YYYYMMDD')` 는 공식 명세 목록에 없습니다. [함수 자동 생성]으로 확인하세요 |
| CalendarSchedule 에 제목이 안 나옵니다 | 날짜 키 이름이 대소문자까지 달랐습니다 | 날짜 키를 SQL 별칭과 대소문자까지 맞추세요 |

### 2-6. 트리 순서가 SP 결과와 다르거나 최상위 노드가 안 잡힙니다
결론: 트리는 조회된 순서대로 그리되, 같은 부모의 자식을 모두 그린 뒤 다음으로 넘어갑니다. 최상위 노드의 상위 노드 키가 0 이면 최상위로 인식하지 못합니다.
할 일:
1. 보이고 싶은 순서대로 SP 에서 ORDER BY 하고, 각 노드의 상위 노드 키가 맞는지 확인하세요.
2. 최상위 노드의 상위 노드 키는 비우거나 모두 같은 값(-1 등)으로 맞추세요.
3. 데이터는 맞는데 노드가 안 보이면 트리가 접힌 상태인지 보세요. 최상위 노드를 펼치면 나타납니다.

### 2-7. 표시 컨트롤 짧은 답
| 질문 | 결론 | 할 일 |
|---|---|---|
| 툴팁을 넣었는데 안 보입니다 | 툴팁은 라벨에만 있고 PC 화면에서 보입니다 | 디버거에서 PC 스타일로 보기를 켜고 확인하세요. 다른 컨트롤 툴팁은 DOM 우회뿐입니다 |
| 배치 그룹 안 텍스트에 말줄임이 안 됩니다 | 배치를 쓰면 최소 너비가 글자 길이만큼 늘어나 말줄임이 걸리지 않습니다 | 텍스트에 [사이즈 고정]을 켜거나 텍스트를 상위 그룹으로 한 번 감싸세요 |
| 멀티인풋박스에 스크립트로 값을 넣고 싶습니다 | 입력 함수는 인풋박스용입니다 | 연결된 컬렉션 키에 `set` 한 뒤 그 그룹을 reload 하세요 |
| 조건에 따라 콤보 목록을 바꾸고 싶습니다 | 콤보를 경우마다 나누는 방법이 안내됐습니다 | 로드 스크립트에서 `Load.control.controlkey('hid')` 로 하나만 보이세요 |
| 행마다 상태별로 버튼 색을 바꾸고 싶습니다 | 로드 스크립트에서 for 문으로 카테고리를 돌면 모든 행이 같은 색이 됩니다 | `Load.sector.<상태키>` 로 그 행 값만 보고 `Load.control.bg.color(...)` 를 부르세요 |
| 탭 진입 때 버튼 show·hide 가 안 먹습니다 | 탭 진입 시점에는 화면이 아직 그려지지 않았습니다 | 버튼 로드 스크립트에서 `Load.control.style('display:none')` 처럼 조건으로 정하세요 |

## 3. 스텝 이동·이벤트 흐름

### 3-1. 스텝 버튼에서 조건이 안 맞으면 이동을 막고 싶습니다
결론: 이동 직전 이벤트에서 중단해도 스텝 버튼의 이동은 일어납니다. 이동 타입을 끄고 스크립트로 이동하세요.
할 일:
1. 스텝 버튼의 스텝 이동 타입을 [안함]으로 바꾸세요.
2. 버튼 이벤트에서 조건을 검사하고, 맞을 때만 `Current.step.moveToNext('<스텝ID>', null, 'toRight')` 를 부르세요.

### 3-2. 슬라이드업 위에 슬라이드업이나 팝업을 겹쳐 열고 싶습니다
결론: 같은 시나리오 안에서는 새 슬라이드업을 열면 앞의 것이 닫히는 것이 기본 동작입니다. 겹치려면 다른 시나리오를 서브시나리오로 여세요.
할 일:
1. 겹칠 화면을 별도 시나리오로 만드세요. 서브시나리오는 자기 자신을 대상으로 할 수 없습니다.
2. 부모 시나리오에서 그 서브시나리오를 슬라이드업으로 열고, 그 안에서 다시 슬라이드업으로 이동하세요.
3. 팝업 안에서 스텝끼리 뒤로가기가 필요하면 팝업 안 스텝은 일반 스텝으로 만들고, 부모에서 서브시나리오를 팝업 타입으로 여세요. 다이얼로그 스텝에서는 직전 스텝 이동이 되지 않습니다.

### 3-3. 서브시나리오에서 돌아오니 Load.sector 에 엉뚱한 값이 들어 있습니다
결론: 서브시나리오 설정의 [콜렉션으로 대체하기]가 켜져 있으면 돌아올 때 컬렉션이 서브시나리오 기준으로 바뀝니다. 데이터 연결이 없는 그룹에서 Load.sector 를 읽어도 같은 증상이 납니다.
할 일:
1. 부모 값을 지켜야 하면 [콜렉션으로 대체하기]를 끄세요.
2. Load.sector 를 읽는 컨트롤이 데이터 연결된 그룹 안에 있는지 확인하세요.

### 3-4. 비동기 작업(외부 호출, 위치 조회)이 끝난 뒤 다음 액션을 실행하고 싶습니다
결론: 이벤트 액션은 비동기 작업을 기다리지 않습니다. 이벤트를 잠시 멈췄다가 작업이 끝나면 다시 이어 가게 하세요.
할 일:
1. 비동기 작업 직전에 `_fEvent.pause();` 를 부르세요.
2. 작업이 끝나는 곳(finally)에서 `_fEvent.resume();` 을 부르세요.
```javascript
_fEvent.pause();
fetch(url).then(r => r.json()).then(data => { /* 값 저장 */ }).finally(() => { _fEvent.resume(); });
```
[확인 필요] `_fEvent.pause`·`resume` 은 공식 답변에 나온 이름이지만 공식 명세 목록에는 없습니다. Studio [함수 자동 생성]으로 확인하세요.

## 4. 스크립트 함수

### 4-1. f.Observer 가 연결되지 않거나 원하는 사람에게만 보내고 싶습니다
결론: 같은 테넌트에서 target 과 eventName 이 같고 다른 사용자일 때 연결됩니다. 보낸 본인은 기본으로 받지 않습니다.
할 일:
1. 받는 쪽과 보내는 쪽의 `f.Observer.init(eventName, target)` 값이 같은지 확인하세요.
2. 특정 사람에게만 보내려면 trigger 메시지에 받을 사용자 값을 넣고, 받는 이벤트에서 자기 사용자 번호와 같을 때만 처리하세요.
3. 같은 계정의 다른 기기에서도 받으려면 init 의 4번째 인자에 true 를 넣으라고 안내됐습니다. [확인 필요] 공식 명세에는 인자가 2개뿐입니다. [함수 자동 생성]으로 확인하세요.
4. 메시지박스가 떠 있으면 받은 이벤트는 닫힐 때까지 대기합니다. 서비스 오류 메시지박스는 대기 중인 이벤트를 비우므로 그 이벤트는 실행되지 않습니다.
확인: 두 브라우저에 다른 사용자로 로그인해 한쪽에서 trigger 하고 다른 쪽 이벤트가 도는지 보세요.

### 4-2. 섹터·스크롤·표시 짧은 답

## 5. K-System 연동

### 5-1. K-System 로그인 SP 는 언제 실행되나요
결론: 로그인 과정에서만 실행되고, 앱 안에서 화면을 옮길 때는 실행되지 않습니다.
| 실행됨 | 실행 안 됨 |
|---|---|
| 세션 만료 뒤 다시 로그인해 처음 들어올 때 | 앱 안에서 시나리오를 옮길 때 |
| 앱을 완전히 종료했다가 다시 실행할 때 | 앱을 종료하지 않고 백그라운드에서 돌아올 때 |
| 백그라운드 앱이 OS 메모리 회수로 종료된 뒤 돌아올 때 | |
할 일: 로그인 SP 결과(메뉴 권한 등)를 바꿨으면 앱을 완전히 종료한 뒤 다시 실행해 확인하세요.

### 5-2. BeforeScript 를 넣은 뒤 서버 통신 오류(502)가 납니다
결론: 빈 DataBlock 에 기본 행을 억지로 넣어 null 값 행을 보낸 경우와, Base64 이미지처럼 아주 긴 값을 보낸 경우에 실제로 생겼습니다.
할 일:
1. BeforeScript 에서 빈 paramBlocks 에 기본 행을 push 하는 코드를 빼고 다시 시험하세요.
2. 이미지가 들어가면 크기를 줄이거나 파일 서비스로 따로 올리세요. 크기 한도는 K-System SP 설명을 보세요.

### 5-3. K-System 파일 모듈로 이미지를 여러 장 보여 주고 싶습니다
결론: 답변 당시에는 이미지 컨트롤의 K-System 모듈이 같은 FileSeq 의 여러 장을 지원하지 않아 같은 이미지가 반복됐고, 여러 장 보기 기능을 넣을 예정이라고 안내됐습니다. 지금 상태는 [확인 필요]입니다.
할 일:
1. 컬렉션 키로 지정한 첨부 번호(AttachFileSeq 등)가 실제로 조회되는지 먼저 확인하세요. 값이 없으면 이미지가 나오지 않습니다.
2. 여러 장이 반복되면 릴리즈 노트에서 K-System 이미지 여러 장 보기 반영 여부를 확인하세요.
3. 등록 뒤 화면에 안 보이면 그 스텝을 reload 하세요. 조회 때 이미지를 줄여 받는 기능은 없습니다(답변 당시).

## 6. FlexSQL·FlexDB

### 6-1. FlexDB 테이블의 컬럼 이름·타입을 바꾸거나 지우고 싶습니다
결론: 컬럼 이름을 바꾸면 기존 컬럼은 남고 새 컬럼이 생깁니다. 타입 변경과 테이블 삭제는 화면에서 할 수 없습니다.
할 일:
1. 컬럼 삭제는 테이블 정보 화면에서 컬럼을 우클릭해 지우세요.
2. 테이블은 [해제]로 연결을 풀거나 플렉스튜디오에 삭제를 요청하세요.
3. 타입 변경은 플렉스튜디오에 요청하세요. 디버거 Test-SQL 의 ALTER 안내도 있었지만 권한 거부로 실패한 사례가 있습니다. 바꾸기 전에 데이터를 내려받아 두세요.

### 6-2. GROUP BY 로 묶어 조회한 화면에서 수정하면 자식 행 키를 잃습니다
결론: 묶어서 조회하면 행마다 고유 키(DataSeq 등)가 사라져 저장 때 어느 행인지 알 수 없습니다.
할 일:
1. 수정까지 해야 하는 화면은 GROUP BY 대신 행 단위로 조회해 고유 키를 남기세요.
2. 목록 SQL 을 그대로 둬야 하면 수정 화면 Init 에서 고유 키를 담은 조회 서비스를 한 번 더 부르세요.

## 7. 알림·외부 API

### 7-1. 알림 API 로 사용자가 관리자에게 알림을 보내려는데 안 갑니다
결론: 알림 API(sendNotice)는 한 번 호출할 때 발신자와 수신자가 같은 테넌트여야 합니다.
할 일: 사용자 앱에서 관리자 앱으로 보낼 때는 관리자가 속한 테넌트를 대상으로 호출하세요. 알림 목록이 한 건만 보이면 반복 카테고리와 데이터 연결을 알림 샘플 시나리오와 비교하세요.

### 7-2. 외부 API(AI 서비스 등)를 붙였는데 응답이 느려 끊기거나 형식이 들쭉날쭉합니다
결론: API 연동의 대기 시간은 20초입니다(답변 당시). 오래 걸리는 작업은 한 번에 기다리지 말고 나눠서 받으세요. SDK 가 없는 서비스도 이벤트 스크립트에서 직접 요청해 붙일 수 있습니다.
할 일:
1. 첫 호출로 작업을 만들고 작업 ID 만 받으세요.
2. 그 ID 로 완료 여부를 몇 초 간격으로 다시 물어(폴링) 끝나면 결과를 받으세요.
3. SDK 가 없는 서비스는 이벤트 스크립트에서 XMLHttpRequest 로 요청하고 결과를 임베드 컨트롤에 보여 주세요.
4. 응답을 JSON 으로 강제하는 설정은 없습니다. 응답이 객체면 그대로, 문자열이면 JSON.parse 하는 도우미 함수를 두세요.
주의: 스크립트에 적은 키는 사용자 브라우저에서 보입니다. 키가 필요한 호출은 [API 연동]에 등록해 서버에서 부르게 하세요.

## 8. 앱 화면 틀·메뉴·다국어

### 8-1. PC 웹에서는 하단탭바를 숨기고 싶습니다
결론: 시작 시나리오 Init 에서 PC 일 때 `f.Frame.tab.hide()` 를 부르면 숨겨집니다. 숨길 때 아래로 내려가는 효과가 보입니다.
할 일: 시작 시나리오 Init 에 기기 판별 뒤 `f.Frame.tab.hide();` 를 넣으세요.
[확인 필요] 안내된 판별 함수 `f.Device.isMobile()` 은 공식 명세 목록에 없습니다. [함수 자동 생성]으로 확인하세요. `f.Frame.tab.hide()` 는 디버거에서 동작하지 않으니 배포 앱에서 보세요.
참고: 로그인 시나리오가 시작페이지면 하단탭에서 뺄 수 없습니다. 홈 시나리오를 시작페이지로 두고, 로그인되지 않았으면 로그인 시나리오로 보내세요.

### 8-2. 상단 홈 버튼·로그아웃 버튼이 원하지 않는 화면에도 보입니다
결론: 레이아웃의 상단헤더를 켜면, 시작페이지가 아닌 화면의 홈 버튼은 그 스텝의 [상단 헤더 사용하기]로 정해집니다. 로그아웃 버튼은 메뉴로 들어간 화면에는 안 보이고 하단탭으로 들어간 화면에는 보입니다.
할 일:
1. 홈 버튼을 감출 스텝에서 [상단 헤더 사용하기]를 끄세요.
2. PC 웹에서 로그아웃 버튼을 아래로 옮기려면 레이아웃관리에서 [동적 앱 설정]을 켜세요.
3. 레이아웃의 우측 버튼은 시작페이지에서만 나옵니다. 다른 화면에 필요하면 그 시나리오에 버튼을 직접 만드세요.
4. 다이얼로그 스텝 높이가 배포 앱에서 다르게 보이면 스텝 디자인 설정의 [헤더 숨기기]를 켜세요.

### 8-3. 다국어가 적용되지 않거나 일부만 바뀝니다
결론: 시나리오 다국어가 앱 다국어보다 먼저 적용됩니다. 줄바꿈, 큰따옴표, 문장 속 값은 정해진 표기를 써야 번역이 맞춰집니다.
할 일:
1. 줄바꿈은 `\n` 대신 `<br>` 로, 큰따옴표는 `&quot;` 로 쓰세요.
2. 문장 안에 값을 넣으려면 Init 에서 `_v` 에 값을 담고 `{{남은 시간은 {% return _v.<값> %}시간입니다.}}` 처럼 쓰세요.
3. 배포 앱에서는 브라우저나 기기 언어를 바꿔 확인하세요.
참고: 날짜 선택 다이얼로그의 년월 글자는 공통 화면이라 사용자 다국어가 적용되지 않습니다. 긴 번역문에 맞춰 글자 크기를 자동으로 줄이는 기능은 없습니다(답변 당시).

### 9-2. 콘솔·운영 짧은 답

| 앱 접속 URL 을 바꾸고 싶습니다 | URL 은 앱 ID 를 따르고 앱 ID 는 바꿀 수 없습니다 | 앱 복사로 새 ID 앱을 만드세요. 플랜별 앱 개수 한도(Business 5개)를 먼저 확인하세요 |

| 로그인 유지 기간이 PC 와 모바일에서 다른가요 | 기기 구분 없이 그 기기에서 처음 로그인한 때부터 설정한 기간이 지나면 만료됩니다 | 기간은 테넌트 [회사 정보]의 세션 유지일에서 정하세요 |
| 누가 실제로 앱을 쓰는지 보고 싶습니다 | 로그인한 사용자는 [앱별 사용자 상태 설정]에서 사용중으로 바뀝니다 | 기기 종류별 통계는 없습니다(답변 당시) |
| 외부 DB 사용자 동기화가 안 됩니다 | FlexSQL 로 동기화하면 필수 컬럼이 있고, 로그인에 휴대폰이나 이메일이 필요합니다 | 사용자 연동의 [SQL 직접연결]에서 필수 컬럼 이름을 확인하세요 |
| SNS 로그인 화면을 꾸미고 싶습니다 | 공통 화면이라 바꿀 수 없습니다 | 초대앱의 로그인 배경 설정은 SNS 로그인 화면에 적용되지 않습니다 |
