# 컨트롤 카탈로그: 무엇에 쓰고, 무엇을 고르고, 어디서 틀리나
이 파일이 답하는 질문: 어떤 입력 컨트롤을 써야 하나요 / InputDate 와 DatePicker 차이는 / ComboBox 와 Radio 와 InputSearch 중 무엇을 쓰나요 / 필수입력을 걸었는데 체크가 안 돼요 / 숨겼는데 필수 체크에 걸려요 / 그룹을 위에 고정하고 싶어요 / 데이터 용도는 무엇을 고르나요 / 체크박스에 0 이 안 들어가요 / Embed 에 script 를 넣고 싶어요 / 이 컨트롤은 어떤 상태를 지원하나요

## 목차

1. 입력 컨트롤 고르는 기준 표
2. 그룹 속성(화면 글자 그대로)
3. 컨트롤 상태와 필수입력 규칙
4. 공통 속성: 이벤트 종류와 클릭 시 스텝 이동
5. 입력 컨트롤
6. 선택 컨트롤
7. 표시, 버튼 컨트롤
8. 파일, 서명, 결재
9. 날짜, 일정 컨트롤
10. 구조 컨트롤(Tab, Tree, Sheet)
11. 문서에 없는 것

근거는 공식 문서(docs.flextudio.com)의 컴포넌트, 개발 모드 쪽입니다. 속성 이름은 Studio 화면에 보이는 글자를 그대로 적었습니다.

## 1. 입력 컨트롤 고르는 기준 표

| 받을 값 | 쓸 컨트롤 | 고르는 이유 |
|---|---|---|
| 한 줄 글자(이름, 코드, 작업지시번호) | InputText | 컨트롤 유형 Text, Password. 앞자리 0 과 영문이 그대로 남습니다 |
| 여러 줄 글자(비고, 사유) | MultiInputBox | 엔터로 줄을 바꿀 수 있습니다 |
| 계산할 숫자(수량, 단가) | InputNumber | 컨트롤 유형 Number(정수), Decimal(소수), Password |
| 시간, 금액, 날짜를 형식에 맞춰 직접 타이핑 | InputMask | 컨트롤 유형 Time(00:00), Money(000,000), Date(0000-00-00) |
| 달력에서 날짜 하나 고르기(필수 체크 필요) | InputDate | 입력창을 누르면 달력이 팝업으로 뜹니다. 필수입력 상태를 지원합니다 |
| 달력에서 여러 날짜나 기간 고르기 | DatePicker | 캘린더 선택 모드에 날짜 선택, 데이터 다중 선택 사용, 기간 선택이 있습니다. 컨트롤 상태는 지원하지 않습니다 |
| 정해진 몇 개 중 하나(펼쳐서 고르기) | ComboBox | 콤보 팝업 설정을 고정 데이터 또는 데이터 소스로 고릅니다 |
| 몇 개 중 하나(항목이 다 보이게) | Radio | 항목은 7개 이하를 권장합니다 |
| 예, 아니오 하나 | CheckBox | 체크하면 "1", 해제하면 "0"(기본값)을 문자열로 저장합니다 |
| 긴 목록에서 검색해 고르기(거래처, 품목, 사원) | InputSearch | 데이터소스를 대상으로 검색합니다. 데이터 다중 선택도 됩니다 |
| 계층 목록에서 고르기(조직, 분류) | Tree | 노드의 키와 상위 노드 키로 계층을 만듭니다 |
| 여러 행을 표처럼 입력 | Sheet (Beta) | 컬럼타입으로 입력 컨트롤 8종을 씁니다 |

- 만든 뒤에 종류를 바꾸려면 디자인 모드의 인풋 컨트롤 변경을 쓰세요. 바꿀 수 있는 컨트롤은 InputText, InputNumber, InputMask, ComboBox, InputSearch, InputDate, MultiInputBox 입니다.
- 필수 체크가 필요한 날짜 입력에는 DatePicker 대신 InputDate 를 쓰세요. 컨트롤별 상태 표에서 DatePicker 는 비활성화, 필수입력, 숨기기, 읽기전용을 모두 지원하지 않습니다.
- 문자 식별자를 InputNumber 로 받으면 안 되는 이유는 화면과 데이터 설명의 컨트롤별 주의에 있습니다.

## 2. 그룹 속성(화면 글자 그대로)

그룹은 그룹과 컨트롤을 감싸는 상자입니다.
Step 의 최상위 컨텐츠이거나 다른 그룹의 하위에 놓입니다. 불필요하게 그룹을 겹겹이 감싸면 성능이 떨어질 수 있습니다.

#### 디자인 모드
| 속성 | 하는 일과 조건 |
|---|---|
| 명칭, 스타일 유형, 스크롤 타입 | 이름 붙이기, 기본 스타일 고르기, 스크롤 방식 고르기 |
| 버튼추가 | 더보기 버튼 추가, 편집 버튼 추가. 이벤트 연결은 개발 모드에서 합니다 |
| 그룹 위치 고정, 위치(상단, 하단) | 스크롤해도 Step 상단이나 하단에 붙어 있습니다. Step 바로 아래 그룹만 쓸 수 있습니다. 고정하면 Explorer 에 핀 아이콘이 붙습니다 |
| 추가기능 선택 | 사용 안함, 체크박스, 추가, 삭제 버튼. 개발 모드에서 데이터 연결을 켠 그룹에서만 보입니다 |
| 사이즈 고정 | 부모 그룹이 배치 속성을 쓸 때만 쓸 수 있습니다 |
| 스플리터 바 | 부모 그룹이 배치를 쓰고, 이 그룹에 px 너비나 높이가 있고, 사이즈 고정이 체크돼 있어야 합니다. 형제 그룹이 둘 이상일 때만 크기가 바뀝니다 |

- 추가기능 선택의 체크박스는 체크한 행 섹터의 상태를 Selected 로 바꿉니다. 전체선택 버튼 활성화도 있습니다.
- 추가, 삭제 버튼의 세부 항목은 항목(행) 삭제 버튼 활성화, 항목(행) 추가 버튼 활성화, 버튼명, 최대 항목(행)개수 설정입니다.
  삭제는 섹터 상태를 Delete 로 바꾸고, 추가는 Added 상태 섹터를 만듭니다.

#### 개발 모드
| 속성 | 하는 일과 조건 |
|---|---|
| 그룹명(그룹아이디) | 그룹 아이디는 그룹명 오른쪽에 보입니다 |
| 컨트롤상태 | 그룹은 숨기기만 씁니다 |
| 로드스크립트 | 그룹이 그려지기 전에 실행됩니다 |
| 데이터 연결 > 데이터 용도 | 기본, 신규 입력, 조회, 상세 보기, 수정 |
| 데이터 연결 > 카테고리명 | 비우면 전체 컬렉션에 연결됩니다. 숫자만으로 된 이름은 쓸 수 없습니다 |
| 데이터 연결 > 필터 사용 | 데이터 용도가 조회일 때만 쓸 수 있습니다 |
| 이너블럭 연결 | 최상위가 아닌 하위 그룹에서만 씁니다. 새 개발은 카테고리 사용을 권장합니다 |
| 이벤트 사용 | 그룹 이벤트는 Click, ScrollEnd 두 가지입니다 |
| 클릭 시 스텝 이동 | 그룹을 누르면 조건에 맞는 Step 으로 이동합니다 |

#### 데이터 용도별 동작
| 데이터 용도 | 그릴 때 섹터를 어떻게 다루나 |
|---|---|
| 기본 | 섹터가 없을 때만 새 섹터를 만듭니다 |
| 신규 입력 | 항상 새 섹터를 만듭니다 |
| 조회 | 지금 있는 섹터들을 가져옵니다 |
| 상세 보기, 수정 | Active 상태인 섹터만 가져옵니다 |

- 데이터 연결을 한 그룹은 reload 할 수 없습니다. 같은 아이디의 그룹이 여러 개 생기기 때문입니다. 상위 요소를 다시 그리세요.
- 필터 사용 안의 상태 필터 화면 글자는 [확인 필요] 입니다. 해당 공식 문서 쪽(필터와 섹터 상태 조건)을 본 뒤 확정하세요. Studio 에서 그룹 > Dev > Data > 필터 사용을 열어 보면 바로 확인됩니다.
- 상위 섹터 기준 필터(Parent Sector Filter)는 데이터 연결의 필터에서만 쓰고, 이너블럭으로 연결할 때 씁니다.

## 3. 컨트롤 상태와 필수입력 규칙

Dev > 컨트롤 상태에서 고릅니다. 로드 스크립트로도 정할 수 있습니다.

| 상태 | 동작 |
|---|---|
| 활성화 | 기본값. 보이고 동작합니다 |
| 비활성화 | 보이지만 동작하지 않습니다 |
| 필수입력 | 활성화에 필수 조건이 붙습니다. Step 이동 때 값이 있는지 검사합니다 |
| 숨기기 | 화면에서 숨깁니다. 필수 체크는 그대로 동작합니다 |
| 읽기전용 | 보이지만 고칠 수 없습니다 |

#### 규칙
1. 필수입력은 컨트롤에 연결된 컬렉션 키를 검사합니다. 컬렉션 키를 연결하지 않으면 필수 체크가 동작하지 않습니다.
2. 검사 대상은 컨트롤이 바라보는 섹터입니다. 화면이 그려진 뒤 그 섹터를 지우면 오류가 날 수 있습니다. 이때는 상위 그룹이나 레이아웃을 다시 그려 섹터를 새로 만드세요.
3. 숨기기 상태의 필수 컨트롤은 여전히 검사됩니다. 그룹을 숨겨도 안쪽 컨트롤 상태는 바뀌지 않습니다. 값이 비면 Step 이 이동하지 않습니다.
4. 스크립트 `f.Component(fid).hide()` 로 숨긴 필수 컨트롤은 필수 체크에서 빠집니다. `show()` 하면 다시 들어갑니다. 상태 값 숨기기와 동작이 다르니 구분하세요.
5. 이벤트 중간에 검사하려면 `f.checkRequired()` 를 쓰세요. 하나라도 비었으면 true 를 돌려줍니다.
6. Step 이동 설정에 필수값 체크 무시 토글이 있습니다. 이동할 Step 이 없을 때는 필수 값 체크하기 토글로 검사만 할 수 있습니다.
7. 값이 비어 이동이 막히면 디버거 실행 내역에 어느 카테고리의 어느 키가 비었는지 나옵니다.

#### 컨트롤별 지원 상태(공식 표 기준, O = 지원)
| 컨트롤 | 비활성화 | 필수입력 | 숨기기 | 읽기전용 |
|---|---|---|---|---|
| InputText, InputNumber, InputMask, ComboBox, InputSearch, InputDate, MultiInputBox, CheckBox, Radio, Approval | O | O | O | O |
| Button | O | | O | O |
| Image | O | O | | O |
| FileUpload(표에는 InputFile) | | O | O | O |
| Signature | | O | | O |
| Tree | | | O | O |
| Text, DatePicker, Line, Calendar Schedule, Embed, CalendarNavigator, TimeTable, Tab | | | | |

- 표의 InputFile 이 FileUpload 와 같은 컨트롤인지는 [확인 필요] 입니다. Studio 의 FileUpload 컨트롤 상태 목록에서 확인하세요.
- 로드 스크립트로 상태를 줄 때도 컨트롤마다 지원 상태가 다릅니다. 위 표를 먼저 보세요.

## 4. 공통 속성: 이벤트 종류와 클릭 시 스텝 이동

| 이벤트 종류 | 발생 시점 |
|---|---|
| Click / ScrollEnd | 클릭 / 스크롤이 끝났을 때 |
| FocusIn / FocusOut | 포커스가 들어갔을 때 / 나갔을 때 |
| Change | 값을 바꾸고 포커스가 나갈 때(입력 컨트롤 기준) |
| Input | 값을 바꾸는 동안 계속 |
| 다이얼로그 닫기 / 선택항목 삭제 | 팝업이 닫힐 때 / 고른 항목을 지울 때 |
| 이전,이후 버튼 클릭 / 스와이프 체인지 / 일자 선택 | 날짜 컨트롤의 이동, 스와이프, 날짜 선택 |

클릭 시 스텝 이동 세부 속성: 스텝 아이디, 스텝 이동 타입(컨트롤의 클릭 이동은 시작스텝, 다음스텝, 직전스텝. 스텝 버튼은 안함, 시작스텝, 다음스텝, 직전스텝 - 마지막 상태, 직전스텝 - 새로 시작의 다섯 가지), 필수값 체크 무시, 다음 스텝이동 애니메이션(우측에서 나오기, 좌측에서 나오기, 밝기변화), 조건.
- 조건에는 if 없이 참, 거짓 식만 쓰세요. 예: `_c.activeSector.orderCount > 0`

## 5. 입력 컨트롤

InputText
- 쓰임: 한 줄 글자 입력. 주요 속성: 컨트롤 유형(Text, Password), 입력가능한 최대 길이, 컬렉션키(멀티), 이벤트 FocusIn, Change, FocusOut, Input.
- 실수: 첫 입력 컨트롤이 Text 이고 두 번째가 Password 이면 브라우저가 아이디, 비밀번호 자동완성으로 채울 수 있습니다.
- 실수: 입력 즉시 반응하려고 Change 를 쓰면 포커스가 나간 뒤에야 실행됩니다. 입력 중 반응은 Input 을 쓰세요.
- 대신: 여러 줄은 MultiInputBox, 계산할 숫자는 InputNumber.

InputNumber
- 쓰임: 숫자 입력. 주요 속성: 컨트롤 유형(Number, Decimal, Password), 입력가능한 최대 길이, 컬렉션키(멀티), 이벤트는 InputText 와 같습니다.
- 실수: 소수를 받는데 Number 를 고르면 정수만 들어갑니다. Decimal 을 고르세요.
- 대신: 코드, 번호처럼 계산하지 않는 값은 InputText.

InputMask
- 쓰임: 시간, 금액, 날짜를 형식대로 직접 입력. 주요 속성: 컨트롤 유형(Time, Money, Date), 기본값(연결된 값이 없을 때 보임), 컬렉션키(멀티).
- 실수: 데이터 연결을 하지 않으면 컬렉션키를 등록할 수 없습니다.
- 대신: 달력에서 고르게 하려면 InputDate.

InputDate
- 쓰임: 입력창을 눌러 달력 팝업에서 날짜 고르기. 주요 속성: 캘린더 종류, 날짜 포맷(YYYY.MM.DD, YYYY-MM-DD, YYYY년MM월DD일, YYYY-MM 등과 직접 입력), 표시될 텍스트, 이벤트 다이얼로그 닫기.
- 실수: 표시될 텍스트를 쓰면 날짜 포맷은 적용되지 않습니다.
- 실수: Data 설정은 일 달력에서만 됩니다.
- 대신: 여러 날짜나 기간은 DatePicker.

MultiInputBox
- 쓰임: 여러 줄 글자 입력. 주요 속성: 콜렉션키(멀티), 이벤트 FocusIn, Change, FocusOut.
- 실수: Input 이벤트는 문서 목록에 없습니다. 입력 중 반응이 필요하면 [확인 필요] 이벤트 사용 목록을 Studio 에서 확인하세요.
- 대신: 한 줄이면 InputText.

## 6. 선택 컨트롤

ComboBox
- 쓰임: 드롭다운에서 하나 고르기. 주요 속성: 표시될 텍스트, 콤보 팝업 설정. 고정 데이터를 고르면 항목명 콜렉션키, 항목 값 컬렉션키, 항목 명, 항목 값을 씁니다. 데이터 소스를 고르면 데이터 소스 명, 셀 타이틀(데이터소스 키), 콜렉션-데이터 소스 키 연결을 씁니다.
- 이벤트: 다이얼로그 닫기, Change. 실수: 데이터 소스 방식에서 고른 값을 어느 컬렉션 키에 저장할지는 콜렉션-데이터 소스 키 연결로 정합니다. 이 연결부터 채우세요.
- 대신: 항목이 많아 검색이 필요하면 InputSearch, 항목을 다 보여 주려면 Radio.

Radio
- 쓰임: 여러 옵션 중 하나만 고르기. 주요 속성: 아이템 가로정렬, 라디오 버튼 우측정렬, 라디오 옵션 타입(고정 데이터, 데이터 소스), 기본값, 라디오박스 항목, 데이터소스 필드, 유니크 키, 콜렉션-데이터소스 키 연결, 선택된 데이터 카테고리로 저장, 이벤트명.
- 실수: 유니크 키에는 매퍼에 정의한 컬렉션키만 넣어야 합니다.
- 실수: 애프터 스크립트는 공식 문서가 권장하지 않습니다.
- 이벤트는 고른 값이 컬렉션키에 반영된 뒤 실행됩니다.
- 대신: 항목이 7개를 넘으면 ComboBox.

CheckBox
- 쓰임: 선택, 해제 하나. 주요 속성: 체크박스 우측 정렬, 기본값이 체크된 상태, 컬렉션키, 체크시 저장될 값(비우면 "1"), 체크 해제 시 저장할 값(비우면 "0"), 이벤트명.
- 실수: 처음부터 "0" 이 들어 있다고 생각하면 틀립니다. 공식 문서는 해제 값이 체크 해제된 경우에만 저장된다고 적습니다. 처음 상태의 키 값은 [확인 필요] 디버거의 데이터 상태에서 확인하고, 스크립트에서는 빈 값도 처리하세요.
- 이벤트는 값이 바뀐 뒤 실행됩니다.
- 대신: 목록 행을 여러 개 고르는 것은 그룹의 추가기능 선택 > 체크박스.

InputSearch
- 쓰임: 데이터소스에서 검색해 고르기. 주요 속성: 표시될 텍스트, 데이터 다중 선택 사용(선택된 데이터 축약해서 보이기, 선택된 데이터 카테고리로 저장, 카테고리명, 이너블럭 키(멀티), 상위 데이터연결과 연결관계 설정), 데이터소스 명, 키워드 검색 시 데이터소스 사용(검색 키워드를 저장할 컬렉션 키), 셀 타이틀(데이터소스 키), 셀 서브 타이틀, 셀 기타 텍스트 추가, 콜렉션 - 데이터소스 키 연결.
- 이벤트: 다이얼로그 닫기, 선택항목 삭제, Change.
- 실수: 데이터소스가 없으면 검색할 대상이 없습니다. 데이터소스를 먼저 만드세요.
- 실수: 서버에서 검색하려면 키워드 검색 시 데이터소스 사용을 켜고, 검색 키워드를 저장할 컬렉션 키 값을 조회 조건으로 쓰세요. 재호출은 검색어 입력 뒤 change 때 일어납니다.
- 대신: 항목이 몇 개뿐이면 ComboBox.
- 선택 이벤트를 거는 정확한 위치는 화면과 데이터 설명의 컨트롤별 주의를 보세요.

## 7. 표시, 버튼 컨트롤

Text
- 쓰임: 글자 보여주기. 주요 속성: 말줄임 사용, 컬렉션 키, 텍스트, 클릭 이벤트 사용, 클릭 시 스텝 이동.
- 실수: 텍스트 칸의 `{=키}` 는 현재 섹터 값만 읽습니다. `_base`, `_v`, 다른 카테고리 값은 `{% %}` 로 쓰세요.
- 실수: 말줄임은 컨트롤 너비가 정해져 있어야 동작합니다.
- 실수: Text 는 컨트롤 상태를 지원하지 않습니다.
- 대신: 사용자 입력이 필요하면 InputText.

Button
- 쓰임: 누르는 버튼. 주요 속성: 버튼에 화살표모양 사용, 버튼명, 클릭 이벤트 사용, 클릭 시 스텝 이동, 버튼 뱃지 사용(뱃지에 표시될 값, 대체 텍스트 가능).
- 실수: Button 에는 필수입력 상태가 없습니다.
- 대신: 하단 고정 버튼은 Step 버튼이나 그룹 위치 고정을 쓰세요.

Image
- 쓰임: 이미지 보여주기(뷰 모드) 또는 올리기(편집 모드). 주요 속성: 새 창으로 이미지 보기, 이미지 여러개 보여주기, 이미지 보여줄 방법 정하기(내 PC에서 업로드, URL, FlexFile, Base64, Ksystem), 이미지 보이기 설정(채우기, 맞추기, 자르기).
  편집 모드에서는 기본 이미지 설정하기, FileKey를 저장할 콜렉션키, FileName을 저장할 콜렉션키, 공유 범위 설정, 폴더 명을 씁니다.
- 실수: 편집 모드는 이미지 한 장만 올리고 바꿉니다. 여러 장은 FileUpload.
- 실수: 폴더 명을 비우면 images 폴더에 저장됩니다.
- 실수: Ksystem, KsystemFile 방식은 K-System 연동 설정이 먼저 있어야 합니다.

Line
- 쓰임: 선 긋기. 고유 개발 속성은 없고, 컨트롤 상태도 지원하지 않습니다.

Embed
- 쓰임: HTML 을 직접 넣기. 주요 속성: Embed HTML.
- 실수: `<script>` 태그는 넣을 수 없습니다. 외부 스크립트는 이벤트에서 `f.Script.load(src, afterEvent, isSync)` 로 URL 을 불러오세요.
- 실수: 컨트롤 상태를 지원하지 않습니다.

## 8. 파일, 서명, 결재

FileUpload
- 쓰임: 파일 올리기. 주요 속성: 타이틀, 비고, Module(FlexFile, KsystemFile, KsystemPayPDF), 파일 정보를 카테고리로 저장, 카테고리명, 이너블럭 키, 콜렉션 키, 상위 데이터 연결관계 설정, 공유 범위 설정, 폴더 명, 콜렉션키(멀티), Const.
- 실수: 콜렉션 키를 비우면 FileKey 가 flexFileKey 에 저장됩니다. 파일 명, 확장자, 크기는 fileName, fileExt, fileSize 에 자동 저장됩니다.
- 실수: 공유 범위를 사용자별로 하면 본인이 올린 파일만 씁니다. 같은 테넌트 사용자끼리 나누려면 테넌트별로 고르세요.
- 실수: 폴더 명을 비우면 files 폴더에 저장됩니다.
- K-System 모듈의 결과 키는 AttachFileNo, FileName, FileUploadDateTime 입니다. KsystemPayPDF 는 XMLString 이 더 있고 별도 계약이 필요합니다.

Signature
- 쓰임: 전자 서명이나 간단한 그리기. 주요 속성: 컬렉션키(멀티), 컨트롤 상태.
- 실수: 읽기전용이면 새로고침(지우기) 버튼이 사라집니다.
- 숨기기 지원은 [확인 필요] 입니다. 상태 표에는 숨기기가 없지만 Signature 쪽 설명은 활성화, 필수입력, 숨기기, 읽기전용 4가지를 적습니다. Studio 의 Signature 컨트롤 상태 목록에서 확인하세요.

Approval
- 쓰임: 결재권자 등록(등록용 컨트롤)과 결재 상태 조회(조회용 컨트롤).
- 등록용 속성: 다이얼로그 데이터 설정(데이터소스 명, 타이틀, 서브타이틀, 비고 데이터키 지정), 결재권자 데이터 설정(컬렉션-데이터소스 키 연결, 매퍼 추가, 결재권자 추가).
- 조회용 속성: 데이터소스 명, 결재 상태텍스트 데이터키 지정, 결재 상태값 데이터키 지정, 결재 승인값 타이틀, 결재 보류값 타이틀, 결재 상태별 컬러 설정.
- 실수: 데이터소스를 연결하지 않으면 다이얼로그가 동작하지 않습니다.
- 실수: 콜렉션-데이터소스 키 연결을 켜지 않으면 컨트롤이 동작하지 않습니다.
- 실수: 결재 상태별 컬러 설정을 한 값에는 승인값, 보류값 기본 색이 적용되지 않습니다.

## 9. 날짜, 일정 컨트롤

DatePicker
- 쓰임: 달력에서 날짜 고르기. 주요 속성: 캘린더 종류, 캘린더 선택 모드(날짜 선택, 데이터 다중 선택 사용, 기간 선택).
- 다중 선택 값은 연결한 카테고리에 저장됩니다. 기간 선택은 시작일과 종료일을 각 컬렉션 키에 저장합니다.
- 실수: 캘린더 선택 모드는 일 달력에서만 쓸 수 있습니다.
- 실수: 컨트롤 상태가 없어 필수 체크를 걸 수 없습니다. 필수 날짜는 InputDate.

CalendarNavigator
- 쓰임: 월, 주, 일 단위로 날짜를 넘기며 고르기. TimeTable 과 함께 예약 화면에 씁니다.
- 주요 속성: 캘린더 네비게이터 종류(월 단위, 주 단위, 일 단위), 날짜 포맷, 초기 세팅 날짜(YYYY, YYYYMM, YYYYMMDD), 날짜 선택 영역 보이기, 선택한 날짜 저장.
- 실수: 날짜 포맷 YYYY-MM-W 는 주 단위에서만 씁니다.
- 이벤트는 3가지입니다. 공통 이벤트 표의 이전,이후 버튼 클릭, 스와이프 체인지, 일자 선택으로 보이지만 [확인 필요] Studio 의 이벤트 사용 목록에서 확인하세요.

Calendar Schedule
- 쓰임: 달력 위에 일정 보여주기. 주요 속성: 년월, 년월 저장 컬렉션키, 선택된 날짜 저장 컬렉션키, 일정표기(텍스트로 표기, 점으로 표기), 일자 선택 이벤트.
- 일자 관련 데이터: 데이터소스 명, 날짜 키, 날짜 타입 키, 날짜 타입별 지정, 일자 innerBlock Key.
- 스케줄 데이터 설정: 데이터소스 명, 날짜 키, 스케줄 타입 키, 스케줄 InnerBlock Key, 타이틀, 서브 타이틀, 스케줄 타입별 디자인 설정.
- 실수: 년월을 비우면 오늘 기준 달이 열립니다.

TimeTable
- 쓰임: 시간 순서 예약(회의실 등). 주요 속성: 캘린더 네비게이터 사용하기, 타임테이블 시간 범위 설정, 예약 항목(데이터소스 명, 항목명 키, 항목데이터 키, 항목정렬 기준 키), 이벤트 데이터, 선택된 시간 데이터 저장, 컬렉션-데이터소스 키 연결, 조회된 이벤트아이템 키, 내가 속한 이벤트, 이벤트 유형별 색상 지정.
- 기본 시간 범위는 8시부터 19시, 30분 간격입니다. 간격은 5분, 10분, 15분, 30분, 1시간 중 고릅니다.
- 실수: 예약 항목은 데이터소스를 연결해야 나옵니다.
- 실수: 클릭 시 스텝 이동은 시나리오에 Step 이 2개 이상일 때만 켜집니다.
- 클릭 이벤트는 조회 된 데이터 클릭 이벤트와 빈 시간 칸을 누르는 추가 버튼 클릭 이벤트 두 가지입니다.

## 10. 구조 컨트롤(Tab, Tree, Sheet)

Tab
- 쓰임: 여러 화면을 한 화면에서 탭으로 전환. 주요 속성: 탭 항목 값 콜렉션 키, 기본값, 탭 항목(탭이름, 스텝명, 탭 항목 값, 이벤트명, 탭 추가). 디자인은 Tab Header 설정, 아이템 배열(컨텐츠 맞춤, 사이즈 고정, 균등분배), Tab Header Item 설정, 선택된 Tab Header Item 설정.
- 실수: 탭 안의 Step 은 Step 버튼을 그리지 않고 Step 이벤트도 실행하지 않습니다. 탭을 열 때 할 일은 탭 항목의 이벤트명에 거세요.
- 실수: 서브시나리오 Step 은 탭에 넣을 수 없습니다.
- 처음 열 탭은 탭 항목 값 콜렉션 키의 값, 없으면 기본값과 같은 탭 항목 값으로 정해집니다.
- 대신: 탭 안의 탭은 화면과 데이터 설명의 컨트롤별 주의를 보세요.

Tree
- 쓰임: 계층 데이터 보여주기와 고르기. 주요 속성: 선택한 아이템 디자인 적용, 전체 접기 및 펼치기 사용, 트리 데이터 검색 사용, 데이터 다중 선택 사용, 데이터소스 명, 컬렉션-데이터소스 키 연결, 노드의 키, 상위 노드 키 항목 설정, 타이틀.
- 이벤트: Selected(노드 선택), Checked(체크박스 체크).
- 실수: 컬렉션-데이터소스 키 연결을 하지 않으면 트리에서 데이터를 쓸 수 없습니다.
- 실수: Checked 이벤트는 데이터 다중 선택 사용을 켰을 때만 씁니다.
- 고정 데이터로 시험할 때는 Title, NodeId, ParentId 형태의 JSON 배열을 데이터소스에 넣으세요. 최상위 노드는 ParentId 를 비웁니다.

Sheet (Beta)
- 쓰임: 스프레드시트처럼 여러 행을 보고, 추가하고, 고치기.
- 주요 속성: 행 높이, 컬럼 명, 최소 행 수, 최소 빈행 수, 컬럼 이동 사용, 열 너비 조정 사용, 행 너비 조정 사용, 행 상태값 사용, 행 삭제 사용, 카테고리명, 상위 데이터 연결과 연결관계 설정.
- 컬럼 컨트롤: 컬럼 명, 컬럼타입, 컬럼 추가, 컬럼단위 정렬 사용, Data(콜렉션 키), 표시될 콜렉션키 추가.
- 컬럼타입은 InputText, InputSearch, InputNumber, InputMask, InputDate, ComboBox, CheckBox, Button 입니다.
- 컬럼 이벤트: Change 는 Button 을 뺀 7종, Click 은 Button, dblClick 은 InputText, InputNumber, InputMask 에서 씁니다.
- 실수: 시트에서 고친 값은 카테고리에 바로 들어가지만, 스크립트로 섹터 값을 바꾸면 시트를 다시 그려야 보입니다. 방법은 화면과 데이터 설명의 시트 컨트롤 다루기를 보세요.
- 실수: 두 컬럼이 같은 콜렉션 키를 쓰면 한 번 고쳐도 두 컬럼에서 Change 가 일어납니다.
- 행 상태값 사용을 켜면 행 번호 자리에 A(추가 또는 빈 행), U(수정된 행)가 보입니다. 행 삭제는 마우스 우클릭 메뉴로 합니다.
- 대신: 행마다 디자인이 다른 목록은 데이터 연결한 그룹(데이터 용도 조회)을 쓰세요.
