## 1. 화면의 구조: Step, 그룹, 컨트롤

시나리오는 Step·이벤트·서비스 세 가지로 이루어집니다.
Step 은 시나리오 안의 화면 하나입니다.
Step 안에 그룹을 놓고, 그룹 안에 컨트롤을 놓습니다.
그룹은 배치를 맡는 상자이고, 데이터 연결을 걸면 카테고리의 행만큼 반복해서 그릴 수 있습니다.

컨트롤 종류(공식 문서 기준)는 다음과 같습니다.

| 분류 | 컨트롤 |
|---|---|
| 입력 | InputText, InputNumber, InputMask, InputDate, MultiInputBox, InputSearch, ComboBox, Checkbox, Radio, DatePicker, FileUpload, Signature |
| 표시 | Text, Image, Line, Embed, Button |
| 목록·구조 | Sheet, Tree, Tab, Approval |
| 일정 | Calendar Schedule, CalendarNavigator, TimeTable |

글자 표시 컨트롤은 문서에 따라 Text 또는 Label 로 적혀 있습니다.
Step 아래쪽 고정 버튼(하단 버튼)은 컨트롤과 따로 설정합니다.

## 2. 데이터의 구조: 컬렉션 > 카테고리 > 섹터

화면에 보이는 값은 모두 컬렉션에 있습니다.

```
_c (컬렉션: 이 시나리오의 모든 행)
 ├─ _c.<카테고리명>   카테고리. 섹터 배열이라 length, [0], forEach, filter 를 쓸 수 있습니다
 ├─ _c.activeSector  지금 선택된 섹터 1개
 └─ 섹터.<키>         값 읽기.  섹터.set('<키>', 값) 으로 값 쓰기
```

| 용어 | 뜻 |
|---|---|
| 컬렉션(`_c`) | 시나리오 하나의 데이터 전체. 시나리오마다 따로 있습니다 |
| 카테고리 | 같은 종류 행의 묶음. 데이터베이스의 테이블 한 개에 해당합니다 |
| 섹터 | 행 하나. 컬렉션 키와 값의 쌍으로 이루어집니다 |
| 컬렉션 키 | 섹터 안의 이름. 데이터베이스의 컬럼에 해당합니다 |

- 섹터는 만들어질 때 `_SUID` 라는 고유 값이 자동으로 붙습니다.
- 서비스 응답은 `_SUID` 를 기준으로 기존 섹터와 합쳐집니다.
- `_v` 는 전역 변수 저장소입니다. Step 을 옮겨도 남고, 서브시나리오와 호출한 시나리오가 같은 `_v` 를 함께 씁니다.

## 3. 데이터 연결과 반복 그룹

규칙: 같은 모양이 반복되는 목록은 카드를 손으로 복제하지 말고, 그룹의 데이터 연결에 카테고리를 지정하세요.

그룹 데이터 연결의 쓰임새는 세 가지입니다.

| 쓰임새(설정값) | 동작 | 언제 |
|---|---|---|
| 조회(`query`) | 카테고리의 행마다 그룹을 한 번씩 그립니다 | 목록, 카드 반복 |
| `detail` | 지정한 섹터 1건만 그립니다 | 목록에서 고른 1건의 상세 |
| `default` | 섹터가 없으면 새로 만듭니다. 카테고리에 N건이면 N번 그려집니다 | 입력 폼 |

[확인 필요] `detail`·`default` 의 Studio 화면 글자는 확인되지 않았습니다. 그룹 속성의 [데이터 용도] 목록에서 확인하세요.

반복 그룹에서 지킬 것은 다음과 같습니다.
1. 행 값을 글자로 보일 때는 `{=<키>}` 를 쓰세요. 반복 행마다 그 행의 값이 나옵니다.
2. 계산이 필요하면 `{% return Load.sector.<키> %}` 를 쓰세요. `{% %}` 안에서 `_c.activeSector` 를 쓰면 모든 행에 같은 값이 나옵니다.
3. `{=<키>}` 는 데이터 연결된 상위 그룹 안에서만 값으로 바뀝니다. 버튼 글자에 `{=<키>}` 가 그대로 보이면 버튼을 감싼 그룹에 카테고리를 연결하세요.
4. `{% %}` 는 그릴 때 한 번만 계산됩니다. 값이 바뀌면 그 글자를 감싼 그룹을 reload 하세요.
5. 같은 카테고리명을 다른 그룹·컨트롤에도 연결하면 행이 반복돼 보입니다.
6. 데이터 연결한 그룹은 서비스나 Init 이벤트에서 그 카테고리에 데이터를 넣어야 화면에 보입니다.
7. 확인 방법: 디버그 실행에서 카테고리의 행 수만큼 그룹이 반복되는지 보세요. 한 번만 그려지면 데이터 연결과 카테고리명을 다시 보세요.

```javascript
// 라벨 글자에 넣는 템플릿 예: 건수 표시
{% return (_c.<카테고리명> || []).length + '건' %}
```
이 코드가 하는 일: 카테고리 행 수를 세어 "N건"으로 보여 줍니다.
카테고리가 없을 때도 오류 없이 0건이 나옵니다.
- 다른 카테고리 값으로 목록을 거르려면 조건 필터 대신 Custom 필터 스크립트를 쓰세요. 조건 필터는 같은 섹터의 키만 봅니다.
- 칸반(상태별 열 + 카드)은 조회 그룹을 두 겹으로 만듭니다. 바깥 그룹이 열(상태 카테고리)을, 안쪽 그룹이 카드를 반복하고 Parent 필터로 부모 키를 맞춥니다.
- 서비스 결과의 자동 화면 반영은 카테고리가 최상위 그룹에 연결된 경우에만 동작합니다. 그 밖의 경우에는 서비스 뒤에 `f.Content('<그룹fid>').reload()` 를 실행하세요.

## 4. activeSector 규칙

| 쓰는 곳 | 돌려주는 것 | 함정 |
|---|---|---|
| `_c.activeSector` | 선택된 섹터. 없으면 화면의 첫 행, 그것도 없으면 컬렉션의 첫 섹터 | 아무것도 안 눌러도 첫 행이 나옵니다 |
| `_c.<카테고리명>.activeSector` | 그 카테고리의 선택 섹터. 없으면 행이 1개일 때만 그 행 | 행이 2개 이상이고 선택이 없으면 비어 있어 `.키` 에서 오류가 납니다 |
| `Load.sector` | 로드 스크립트·`{% %}` 에서 지금 그리는 행 | 이벤트 스크립트에서는 쓰지 않습니다 |

- `activeSector` 는 속성입니다. 괄호 없이 쓰세요.
- 그룹이나 캔버스 버튼을 누르면 이벤트보다 먼저 그 행이 선택됩니다. 반복 그룹 안 버튼의 이벤트에서는 누른 행이 activeSector 입니다.
- 시트 행은 한 번 클릭으로 activeSector 가 바뀌지 않고 더블클릭에서 바뀝니다.
- 이벤트 스크립트에는 `sector` 라는 변수가 없습니다. 행은 `_c.<카테고리명>.activeSector` 로 꺼내세요.

규칙: 저장·삭제 전에는 꺼낸 섹터가 정말 그 행인지 키 값으로 확인하세요.

```javascript
var target = (_c.<카테고리명> || []).length ? _c.<카테고리명>.activeSector : null;
if (!target || !target.<키>) {
  f.Toast().title('<행을 먼저 선택하세요>').delay(2).position('center').show();
  f.Event().break();
  return;
}
```
이 코드가 하는 일: 선택한 행이 없거나 키가 비어 있으면 안내를 띄우고 이 이벤트의 남은 액션을 멈춥니다.

## 5. 값 바꾸는 방법 차이

규칙: 섹터 값은 `sector.set('<키>', 값)` 으로 바꾸세요.

| 방법 | 수정 상태 표시 | 연결된 컨트롤 자동 갱신 | 판단 |
|---|---|---|---|
| `섹터.set('<키>', 값)` | 붙습니다 | 그 섹터·키에 연결된 컨트롤을 다시 그립니다 | 기본 |
| `섹터.setValue('<키>', 값)` | 붙습니다 | 하지 않습니다 | 화면 갱신이 필요 없을 때 |
| `섹터.<키> = 값` | 붙지 않습니다 | 하지 않습니다 | 쓰지 마세요 |
| `f.Collection.updateSector(...)` | 붙습니다 | 마지막 인자가 true 면 set, false 면 setValue 와 같습니다 | 여러 행을 한 번에 |

- 직접 대입하면 수정 상태가 붙지 않습니다. 그래서 수정된 행만 보내는 저장 서비스에서 그 행이 빠집니다.
- `set` 은 키와 값을 여러 쌍 받습니다. 예: `섹터.set('<키1>', 1, '<키2>', 2)`.
- 한 이벤트 안에서 `set` 과 직접 대입을 섞지 마세요.
- 목록 필터, 건수, `{% %}` 문구, 다른 섹터를 참조하는 표시는 `set` 만으로 바뀌지 않을 수 있습니다. 감싼 그룹을 reload 하세요.
- 데이터베이스 값과 화면 메모리(컬렉션)는 별개입니다. 저장한 뒤에도 화면을 바꾸려면 `set` 으로 메모리를 고치거나 다시 조회하세요.

## 6. 행 상태(added·updated·deleted)

섹터에 붙는 상태는 added·updated·deleted 세 가지뿐입니다.
K-System(Flex-K) 저장 SP 에는 이 상태가 WorkingTag(A·U·D)로 전달됩니다.

| 행을 만든 방법 | 상태 | WorkingTag |
|---|---|---|
| 시트 빈 행에 입력 | added | A |
| 데이터 연결의 새 섹터, `f.Content(fid).addRow(...)` | added | A |
| `f.Collection.addSector({...}, '<카테고리명>')` | 비어 있음 | U |
| 서비스로 조회해 받은 행 | 비어 있음 | U |
| 위 행을 set·setValue·시트 편집으로 고침 | updated (added 였으면 added 유지) | added 였으면 A, 아니면 U |
| 저장 전 새 행을 `섹터.delete()` | 메모리에서 바로 사라짐 | 보내지 않음 |
| 저장된 행을 `섹터.delete()`, 시트 행 삭제 | deleted | D |
| `f.Collection.removeSector(...)` 로 지움 | 메모리에서 사라짐 | 보내지 않음 |

- 스크립트로 만든 새 행을 신규로 저장하려면 만든 직후 `setStatus('added')` 를 부르세요.
- `setStatus` 인자는 소문자 `'added'`, `'updated'`, `'deleted'` 만 됩니다.
- 서버에서도 지워야 하는 행은 `섹터.delete()` 로 지우세요. `removeSector` 는 화면 메모리에서만 버립니다.
- 현재 상태는 `섹터.isAdded`, `섹터.isUpdated`, `섹터.isDeleted` 로 읽으세요.
- A·U·D 외의 상태(예: X)는 없습니다. 필요하면 상태용 컬렉션 키를 따로 만들어 관리하세요.

```javascript
var row = f.Collection.addSector({ <키1>: '<값1>', <키2>: '<값2>' }, '<카테고리명>');
row.setStatus('added');
f.Content('<그룹fid>').reload();
```
이 코드가 하는 일: 카테고리에 새 행을 하나 만들고 신규(added) 표시를 붙입니다.
저장 SP 에 A 로 전달되고, 감싼 그룹을 다시 그려 화면에 보입니다.

## 7. f.Collection 함수와 인자 순서

함수마다 인자 순서가 다릅니다.
가능하면 Studio 스크립트 액션의 [함수 자동 생성]으로 뽑아 쓰세요.

| 함수 | 인자 순서 | 주의 |
|---|---|---|
| `addSector(obj, category)` | 데이터, 카테고리 | 새 `_SUID` 로 복제됩니다. 상태가 비어 있습니다 |
| `removeSector(status, category)` | 상태 먼저 | 카테고리를 비우면 컬렉션 전체가 대상입니다 |
| `updateSector(status, key, value, category)` | 상태, 키, 값, 카테고리 | 카테고리를 비우면 전체가 대상입니다 |
| `moveCategory(category, status, newCategory)` | 카테고리 먼저 | removeSector 와 순서가 반대입니다 |

- 그 밖에 `createCategory(category)`, `removeCategory(category)`, `filter(key, 연산자, 값)` 가 있습니다.
- 상태 값은 `'all'`, `'active'`, `'selected'`, `'added'`, `'updated'`, `'deleted'` 입니다. 빈 문자열도 전부를 뜻합니다.
- 상태 값은 소문자로 쓰세요. `'All'` 처럼 쓰면 오류 없이 빈 데이터가 넘어갑니다.
- 행을 다른 카테고리로 옮길 때는 `addSector` 가 아니라 `moveCategory` 를 쓰세요. `addSector` 는 복제라 같은 값이 두 행이 됩니다.
- `filter` 는 카테고리를 가리지 않고 키 이름만 봅니다. 여러 카테고리에 같은 키가 있으면 다른 카테고리 행이 잡힙니다.
- 카테고리의 마지막 행을 지우면 카테고리 자체가 사라집니다. 읽을 때는 `(_c.<카테고리명> || [])` 로 감싸세요.

## 8. 시트 컨트롤 다루기

시트의 행은 연결된 카테고리의 섹터입니다.
스크립트에서 시트 값을 읽을 때는 시트가 아니라 `_c.<카테고리명>` 을 읽으세요.
- 사용자가 셀을 고치면 그 섹터에 updated 가 붙습니다. 빈 행에 입력하면 added 행이 생깁니다.
- 시트 행 삭제는 섹터를 deleted 상태로 바꿉니다. 메모리에서는 남아 있습니다.
- 시트 편집은 다른 컨트롤을 자동으로 다시 그리지 않습니다.
- 시트는 모바일 앱에서 쓸 수 없습니다.

스크립트로 시트를 다룰 때는 `f.SheetControl('<시트fid>')` 를 씁니다.
이벤트 스크립트에서만 동작합니다.

| 하고 싶은 일 | 쓰는 함수 |
|---|---|
| 섹터를 바꾼 뒤 시트에 반영 | `reloadData()`, `syncData()`, `syncSector(섹터)` |
| 시트 전체 다시 그리기 | `reloadSheet()` |
| 빈 행 추가, 행 삭제 | `addEmptyRow(n)`, `deleteRow(섹터)` |
| 정렬 | `sort(키, 'asc')` |
| 스크롤·포커스 | `Scroll.toTop()`, `Scroll.toRowAtVisual(행)`, `Focus.toSectorCell(섹터, 키)` 등 |

```javascript
var s = _c.<카테고리명>.activeSector;
s.set('<키>', <값>);
f.SheetControl('<시트fid>').reloadData();
```
이 코드가 하는 일: 선택한 행의 값을 바꾸고 시트에 다시 반영합니다.
- `setCellValue` 라는 함수는 없습니다. 셀 값은 섹터의 `set` 으로 바꾸세요.
- 반복 그룹 안에 같은 시트가 여러 개면 두 번째 인자로 섹터를 넘겨야 원하는 시트를 잡습니다.
- [확인 필요] `syncSector`·`deleteRow` 의 인자가 섹터 1개인지 배열인지 문서끼리 다릅니다. [함수 자동 생성] 결과를 따르세요.
- `f.Sheet.download`, `f.Sheet.formatDownload`, `f.Sheet.insert` 는 엑셀 내려받기·올리기용이고 PC 웹에서만 동작합니다.
- 시트 셀 안의 Search 는 더블클릭해야 열립니다. 바꾸는 설정은 없습니다.
- 공식 답변 기준으로 행 단위 편집 잠금, 셀 단위 readOnly, 열 고정, 시트 필터는 지원하지 않습니다. readOnly 는 컬럼 단위로만 됩니다.
- 기본 행 삭제 메뉴에는 이벤트를 걸 수 없습니다. 삭제에 처리가 필요하면 별도 삭제 버튼을 만들고 `deleteRow` 를 쓰세요.

## 9. 화면 갱신: f.Content 와 reload

`f.Content('<그룹fid>')` 는 그룹·레이아웃을 다루며 이벤트 스크립트에서만 동작합니다.
제공 함수: `reload()`, `reloadWithAnimation()`, `addRow(카테고리명)`, `delRow()`, `show()`, `hide()`, `selectAll()`, `deselectAll()`, `Scroll`.

| 상황 | 할 일 |
|---|---|
| 일부 영역만 다시 그리기 | `f.Content('<그룹fid>').reload()` |
| 데이터 연결 그룹을 reload 했더니 복제가 꼬임 | 데이터 연결 그룹을 연결 없는 그룹으로 한 겹 감싸고 감싼 그룹을 reload |
| Step 전체 다시 그리기 | `Current.step.reload()` (Init·Loaded 를 다시 실행하지 않습니다) |
| Init·Loaded 부터 다시 | `Current.step.restart()` |

- Step 전체 reload 는 선택 상태를 풀고 깜빡임이 생깁니다. 필요한 그룹만 reload 하세요.
- 컨트롤 이벤트에서 Step reload 를 걸면 무한 reload 가 될 수 있습니다.
- `f.Event().break()` 와 함께 쓸 때는 break 를 먼저, reload 를 그 뒤에 두세요. 반대로 두면 시트가 사라질 수 있습니다.

## 10. 컨트롤별 주의

- 문자 식별자(작업지시번호 등)는 InputText 를 쓰세요. InputNumber 는 앞자리 0 과 영문을 없앱니다.
- InputText 이벤트는 focusin, focusout, change, input 네 가지이고 Enter 전용 이벤트는 없습니다.
- InputText 의 input 이벤트에서 `set` 으로 값을 바꿔도 입력창 글자는 그대로입니다. [확인 필요] 문서의 `f.Component('<fid>').setInputValue(<값>)` 로 바뀌는지 디버그 실행으로 확인하세요.
- InputSearch·ComboBox 의 선택 이벤트는 본체가 아니라 안쪽 목록(List)에 거세요.
- 필수 체크는 컨트롤에 연결된 모든 컬렉션 키를 검사합니다. 데이터소스 쪽 키가 비어도 오류가 납니다.
- `f.Component('<fid>').hide()` 로 숨긴 필수 컨트롤은 필수 체크에서 빠지고, `show()` 하면 다시 들어갑니다.
- 탭 안에 탭(2단계 이상 Tab)은 지원하지 않습니다. 안쪽을 Radio, Step 이동, 팝업으로 바꾸세요.
- 팝업 Step 높이를 내용에 맞춰 자동으로 바꾸는 기능은 없습니다. 높이를 지정하지 않으면 전체 화면으로 열립니다.

## 11. 레이아웃과 스타일

로드 스크립트(LoadScript)는 컨트롤·그룹을 그리기 직전에 실행됩니다.
`Load.*` 는 로드 스크립트에서만, `f.Component`·`f.Content`·`f.SheetControl` 은 이벤트 스크립트에서만 씁니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 스타일 직접 지정 | `Load.control.style('<CSS>')`, `Load.layout.style('<CSS>')`. 같은 항목이면 속성 설정보다 우선합니다 |
| 클래스 붙이기 | `Load.control.addClass('cust_<이름>')`. 클래스 이름은 `cust_` 로 시작해야 합니다 |
| 조건부 숨김 | `Load.control.controlkey(<조건> ? 'hid' : '')` 후 부모 그룹 reload |
| 버튼을 비활성처럼 | `Current.control.style('background-color:<색>;color:<색>;pointer-events:none;')`. `controlkey('dis')` 로는 안 됩니다 |

외부 CSS·JS 파일은 다음 순서로 넣습니다.
1. Studio 탐색기에서 시나리오 이름을 누르세요.
2. 시나리오 설정의 [외부파일설정]에 파일 주소를 넣으세요.
3. 주소는 `https://` 로 시작하고 `.css` 나 `.js` 로 끝나야 합니다.
4. 특정 그룹을 고르는 선택자는 `section[data-metaid="<그룹fid>"]` 를 쓰세요.

쿼리가 붙는 주소(SDK 등)는 이벤트 스크립트에서 `f.Script.load('<주소>', '<로드후이벤트명>')` 로 불러오세요.
- `Load.control` 로 바꾼 것은 그 한 번의 그리기에만 적용됩니다. `Load.layout` 으로 바꾼 그룹 설정은 다시 그려도 남습니다.
- 반복 그룹에서 조건에 따라 스타일을 바꿀 때는 참·거짓 양쪽 스타일을 모두 적으세요. 한쪽만 적으면 다른 행에 남습니다.
- 로드 스크립트로 라벨 폭을 바꾸려면 라벨 폭을 고정값으로 두세요. 글자맞춤 폭이면 무시됩니다. `%` 보다 px 를 쓰세요.
- 세로로 쌓은 그룹이 눌려 잘리면 내용 높이를 지킬 그룹에 고정 크기 사용을 켜세요. [확인 필요] 이 설정의 화면 글자는 확인되지 않았습니다.
- Embed 의 HTML 안 `<script>` 는 실행되지 않습니다. 라이브러리는 [외부파일설정]으로, 그리는 코드는 Loaded 이후 이벤트의 스크립트 액션에 두세요.
- 화면 요소(DOM)를 직접 건드리는 코드는 제품 기능 밖입니다. 꼭 필요하면 요소를 `data-metaid="<fid>"` 로 찾으세요. 렌더된 id 는 그릴 때마다 바뀝니다.

## 12. 컬렉션 키 예약어와 이름 규칙

아래 이름을 컬렉션 키로 쓰면 값이 저장되지 않습니다.

| 종류 | 쓰면 안 되는 이름 |
|---|---|
| 섹터 속성 | block, collection, innerBlocks, isActive, isAdded, isDeleted, isLast, isSelected, isUpdated, keys, status |
| 섹터 함수 | activate, delete, remove, select, unSelect, set, setValue, setStatus, release, mergeSector, replaceSector |

- 상태 컬럼은 `<업무접두어>Status` 처럼 접두어를 붙이세요. 예: `ASStatus`.
- 공식 문서 예시에 `set('status', ...)` 가 있지만 `status` 는 예약어라 그대로 따라 쓰지 마세요.
- 키 앞뒤 공백은 화면에서 보이지 않지만 다른 키로 취급됩니다. 같은 이름이 두 번 보이면 공백을 의심하세요.
- 특수문자는 키에 쓰지 마세요.
- SQL·SP 결과의 컬럼 이름(별칭)은 컬렉션 키와 글자까지 같아야 화면에 값이 나옵니다.

## 13. 자주 나는 문제 표

| 보이는 것 | 원인 | 조치 |
|---|---|---|
| 고른 1건만 보여야 하는데 카드가 N번 복제됩니다 | 그룹 쓰임새가 `default` 입니다 | `detail` 로 바꾸고 대상 섹터를 지정하세요 |
| 반복 행마다 같은 값이 나옵니다 | `{% %}` 에서 `_c.activeSector` 를 썼습니다 | `Load.sector.<키>` 로 바꾸세요 |
| 아무 행도 안 눌렀는데 첫 행이 저장·삭제됩니다 | activeSector 가 첫 행으로 대체됩니다 | 저장 전에 키 값을 확인하세요 |
| `Cannot read properties of undefined (reading 'length')` | 마지막 행 삭제로 카테고리가 사라졌습니다 | `(_c.<카테고리명> \|\| [])` 로 감싸세요 |
| 값을 바꿨는데 저장 서비스에 안 실립니다 | 직접 대입이라 수정 상태가 없습니다 | `set` 으로 바꾸세요 |
| SP 에 A 로 가야 하는데 U 로 갑니다 | `f.Collection.addSector` 행은 상태가 없습니다 | 만든 직후 `setStatus('added')` 를 부르세요 |
| 삭제했는데 DB 에서 안 지워집니다 | `removeSector` 는 메모리만 지웁니다 | `섹터.delete()` 후 저장하세요 |
| `status` 키에 값이 안 들어갑니다 | 예약어입니다 | 접두어를 붙인 이름으로 바꾸세요 |
| 쿼리는 되는데 시트에 값이 안 나옵니다 | 컬럼 별칭과 키가 다르거나 카테고리명이 다릅니다 | 별칭·카테고리명을 맞추세요 |
