# 플렉스튜디오 문의 양식

이 양식이 쓰이는 때: 오류를 진단받거나 담당자에게 문의할 때 / 무엇을 보내야 하는지 모를 때

아래 칸을 채워 보내 주세요.
모르는 칸은 비워 두셔도 됩니다.
오류 문구는 화면 캡처보다 텍스트 복사가 더 정확합니다.

## 보내지 마세요

- 비밀번호, 인증번호, API 키 실제 값
- 브라우저 Network 화면의 Cookie 값(캡처할 때 가려 주세요)
- 다른 사람의 휴대폰 번호와 이메일(캡처할 때 가려 주세요)

## 2. 언제, 어떤 환경에서 났나요

| 항목 | 적을 내용 |
|---|---|
| 발생 시각 | 날짜와 시각(분 단위까지) |
| 실행한 곳 | Studio 디버거 / PC 브라우저 / 모바일 앱 / PDA |
| 기기와 브라우저 | 예: Windows 11 Chrome, Android 휴대폰, PDA 모델명 |

브라우저 F12 콘솔에 빨간 오류가 있으면 그 문구도 붙여 주세요.

```text
<오류 문구를 여기에 그대로 붙여 넣으세요>
```

## 4. 재현 순서

처음 화면부터 오류가 날 때까지 한 줄에 한 동작으로 적어 주세요.

1. `<예: 앱에 로그인합니다>`
2. `<예: 출근 화면에서 [조회] 버튼을 누릅니다>`

## 6. 캡처

- 오류가 보이는 화면 전체
- 서비스 오류라면 그 서비스의 [보내는 데이터]와 [받는 데이터] 설정 화면
- Studio 디버거 실행 내역에서 오류가 찍힌 부분
